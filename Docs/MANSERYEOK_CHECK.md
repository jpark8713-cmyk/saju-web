# 만세력 앱 비교 점검 목록

시중 만세력 앱과 우리 엔진의 계산 결과를 비교하는 목록이에요. 직접 비교는 앱마다 계산 방식이 갈리는 일주·시주·대운(자시, 경도 보정, 서머타임, 대운수 반올림)에 집중하고, 절입 시각·음력 변환처럼 공식 자료와 기계로 대조할 수 있는 것은 따로 확인했어요.

- 채우기 페이지: 앱 이름·설정과 사례별 앱 결과를 입력하면 저장돼요(링크는 보고 메시지에 있어요). 이 문서의 표와 같은 값이에요.
- 우리 결과는 커밋 `0aab20f` 기준으로 계산했어요(유료 호출 없음). 기준일 2026-10-29.
- 결과는 `LAUNCH_CHECKLIST` 1-8(자시 기본값)과 1-9(절입 경계 기대값)를 닫는 데 써요.

## 우리 계산 기준(먼저 읽어 주세요)

- **절입 판정(년·월주):** 시계 시각 기준이에요. 태어난 순간(표준시·서머타임 반영)을 절입 순간과 비교하고, 경도 보정은 쓰지 않아요.
- **경도 보정(일주·시주):** 출생지 경도 × 4분을 세계시에 더해 평균태양시를 구해요(균시차는 쓰지 않아요). 동경 135°(한국 표준시 기준)와의 차이만큼 늦어져요.
  - 서울 126.98°: 135 − 126.98 = 8.02° × 4분 = **32분 5초**. 분 미만은 버려서, 정각 분으로 넣은 시각은 보정 시각이 **33분** 앞당겨 보여요(예: 23:50 → 23:17:55 → 23:17). 실제 보정은 32분 5초이고, 33분은 초를 버린 결과예요.
  - 그래서 서울은 시계로 홀수 시의 33분(23:33, 01:33, 07:33 …)부터 다음 시(時)예요. 강릉 128.88°는 24분 29초라 시계로 25분(07:25 등)부터예요.
  - 경도 값 출처: `src/config/regions.ts`의 시청·군청·구청 소재지 대략값(서울 126.98° = 서울시청 부근). 공식 자료 대조는 `LAUNCH_CHECKLIST` 1-10에 남아 있어요.
- **10번·12번은 보정 폭 1~3분 차이로 결과가 갈리는 경계예요.** 앱이 서울을 30분(동경 127.5°)이나 32분으로 보정하면 10번(23:30)이 자시가 될 수 있어요. 12번(강릉 07:25)은 진시 첫 1분이라 1분만 덜 보정해도 묘시가 돼요.

|---|---|---|

| 엔진(lunar-javascript 1.7.7) | 2011-11-08 03:34:56 | 베이징시 02:34:56을 한국 시각으로 바꾼 값 |

- 같은 방법으로 같은 달 다른 절기를 검산하면 천문연 값과 맞아요(2011 상강 03:30 → 210.004°, 소설 01:08 → 240.005°). 입동 행만 약 6시간 어긋나요.

- 테스트(`tests/engine/kasi.test.ts`)는 천문연 값이 그 오류 범위(09:21~09:31) 안이고 엔진 값이 독립 계산 ±15분 안일 때만 예외로 봐요. 천문연이 값을 고치면 테스트가 실패해 예외를 지우게 돼요.
